- про метод check_product_parameter:

Сообщение о том, что товар добавлен в корзину. Название товара в сообщении должно совпадать с тем товаром, который вы действительно добавили.

- маркировка sleep
Этой маркировкой отделил тесты группы user и guest для удобства тестирования (что бы не включалось лишнее)
Что бы заработали тесты под этой маркировкой, пишем -m "sleep", что бы работали все тесты кроме помеченных этой маркировкой, пишем -m "not sleep".
*не конфликтует с -m need_review, с этой маркировкой включатся только тесты need_review

- из теста с параметризацией убрал ненужные ссылки для удобства и скорости, оставил только один успешный, и xfail

- [опционально] для отображения логирования запускай pytest -s *всё остальное*, так удобнее читать логи
